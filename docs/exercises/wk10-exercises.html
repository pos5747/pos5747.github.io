Exercise 1 Simulate and Recover; Ordered Logit

One important way to test and develop your understandings of statistical models and quantities of interest is to simulate a fake data set with known true quantity of interest (e.g., coefficients or first difference) and then recover that quantity of interest through your estimation procedure.

  • Week 9 did this for logit: Simulate and Recover; Logit.

Do this for the ordered logit model in the notes. As your quantity of interest, use \(\Pr(y \geq 3)\) when income equals 1.5 and x2 equals "Label 1".

  1. First, simulate a fake data set with known cutpoints, coefficients, and quantity of interest. The code below handles this. Notice that the linear predictor eta has no intercept. The cutpoints alpha take its place.
  2. Second, use MASS::polr() to fit an ordered logit model to the fake data. Are the true cutpoints and coefficients inside their 95% confidence intervals? (polr() calls the cutpoints “Intercepts” and labels them 1|2, 2|3, and 3|4.)
  3. Third, use predictions() to recover the true quantity of interest. Is the true value inside the 95% CI?
  4. Fourth, adapt the code to compute the true first difference in \(\Pr(y \geq 3)\) as income moves from −1.5 to 1.5 (with x2 equal to "Label 1"). Then recover it with comparisons().
  5. Fifth, refit the model with brm(family = cumulative("logit")). Recover the cutpoints, the coefficients, and the first difference. Compare with polr() and the truth.
# --- simulate a fake data set ---

# set seed for reproducibility
set.seed(1234)

# set sample size
n <- 10000  # needs to be large enough so that CI isn't super wide

# create explanatory variables
## numeric variable; six brackets, like income in the anes data
income <- sample(c(-2.5, -1.5, -0.5, 0.5, 1.5, 2.5), size = n, replace = TRUE)
## qualitative variable
x2 <- sample(c("Label 1", "Label 2"),
             size = n,
             replace = TRUE,
             prob = c(0.75, 0.25))  # about 75% will be "Label 1"

# create cutpoints and coefficients
alpha <- c(-1, 0.5, 2)  # J - 1 = 3 cutpoints, so J = 4 categories
b1 <- 0.4
b2 <- 1

# linear predictor; no intercept!
eta <- b1*income + b2*(x2 == "Label 2")

# cumulative probabilities Pr(y <= j), j = 1, 2, 3
cp1 <- plogis(alpha[1] - eta)
cp2 <- plogis(alpha[2] - eta)
cp3 <- plogis(alpha[3] - eta)

# category probabilities Pr(y = j), j = 1, 2, 3, 4; one row per observation
p <- cbind(cp1, cp2 - cp1, cp3 - cp2, 1 - cp3)

# simulate outcome for ordered logit model; one draw per observation
y <- numeric(n)
for (i in 1:n) {
  y[i] <- sample(1:4, size = 1, prob = p[i, ])
}

# combine into data frame; y must be an ordered factor for polr()
data <- data.frame(y = factor(y, ordered = TRUE), income, x2)

# truth: Pr(y >= 3) when income = 1.5 and x2 = "Label 1"
eta_c <- b1*1.5  # x2 = "Label 1", so the b2 term is zero
1 - plogis(alpha[2] - eta_c)
[1] 0.5249792

\(\Pr(y \geq 3)\) is the sum of the probabilities of categories 3 and 4.

Complete solution

Part 1

The true value of \(\Pr(y \geq 3)\) is about 0.525. Notice that \(\Pr(y \geq 3) = 1 - \Pr(y \leq 2) = 1 - \operatorname{logit}^{-1}(\alpha_2 - \eta)\), so we only need the second cutpoint.

Exercise 2 Eight Schools

In my slides, I motivated hierarchical models with the “309 problem.” There’s a similar motivational problem called the “eight schools” problem. This example is worth studying carefully.

  1. Read this blog post (by Phil Price) on Andrew Gelman’s blog: “Everything I need to know about Bayesian statistics, I learned in eight schools.”
  2. Read the pp. 119-124 of BDA3 on the eight schools problem.
  3. Run the R code here. Note that the notation in my Stan model differs from BDA3.
  4. In the model, \(\sigma\) captures the similarity of the treatment effects across school districts. I give this parameter a half-Cauchy prior with a scale of 20. (See the note below.) How does changing the scale of the half-Cauchy prior in the Stan model affect the estimates of \(\sigma\)?
    1. Try setting the scale of the half-Cauchy to 5 instead of 20.
    2. Try setting it to 100. Hint: you can use sigma_draws <- spread_draws(fit, sigma) to get a convenient data frame of posterior simulations of \(\sigma\).

Make sure you understand the basic eight schools example and can discuss it in parallel to the 309 example in the slides.

So what’s a half-Cauchy?

A Cauchy distribution is a location-scale t distribution with one degree of freedom. The half-Cauchy is centered at zero and folded over, so that it is just the rightward half. It has only a scale parameter that corresponds to something like the “expected” value of \(\sigma\).1 The expected value of the half-Cauchy does not exist, but the median equals the scale parameter. This is a useful weakly informative prior for variance parameters that capture similarity in hierarchical models.

In this case, the student-level SAT scores range from 200 to 800, and the treatment effects are somewhere around a 10-point improvement. In the Stan model, \(\sigma\) is the SD around that 10-point effect across schools. \(\sigma = 20\) would be huge variation; \(\sigma = 3\) or \(\sigma = 5\) seem “about right.” So I think of a half-Cauchy with a scale of 20 as a “weakly informative” prior that only rules out absurdly large values of \(\sigma\) and gently encourages smaller rather than larger values.

# load packages
library(cmdstanr)
library(tidybayes)

# eight-schools data; from my 2nd ed. of BDA on p. 140
est <- c(28, 8, -3, 7, -1, 1, 18, 12)
se_est <- c(15, 10, 16, 11, 9, 11, 10, 18)
J <- length(est)

# the stan model from the script (centered), with the prior scale as data
stan_code_centered <- "
data {
  int<lower=1> J;
  vector[J] est;
  vector<lower=0>[J] se_est;
  real<lower=0> scale;  // scale of the half-cauchy prior on sigma
}
parameters {
  real mu;
  real<lower=0> sigma;
  vector[J] theta;
}
model {
  mu ~ normal(0, 1000);
  sigma ~ cauchy(0, scale);
  theta ~ normal(mu, sigma);
  est ~ normal(theta, se_est);
}
"
model_centered <- cmdstan_model(write_stan_file(stan_code_centered))
fit_centered <- model_centered$sample(
  data = list(J = J, est = est, se_est = se_est, scale = 20),
  seed = 123,
  chains = 4,
  parallel_chains = 4,
  iter_warmup = 2000,
  iter_sampling = 2000
)

# pull the draws and diagnostics into memory (cmdstanr keeps them in temp files)
centered_summary <- fit_centered$summary(variables = c("mu", "sigma"))
centered_diagnostics <- fit_centered$diagnostic_summary()

  • A known problem with this model: when sigma is small, the thetas must sit close to mu, and the sampler can’t move through that region.
  • The fix is the non-centered parameterization: sample standardized effects z and set theta = mu + sigma * z. Same model, easier posterior.

Part 4

# non-centered version: same model, theta = mu + sigma * z
stan_code_noncentered <- "
data {
  int<lower=1> J;
  vector[J] est;
  vector<lower=0>[J] se_est;
  real<lower=0> scale;  // scale of the half-cauchy prior on sigma
}
parameters {
  real mu;
  real<lower=0> sigma;
  vector[J] z;  // standardized school effects
}
transformed parameters {
  vector[J] theta = mu + sigma * z;
}
model {
  mu ~ normal(0, 1000);
  sigma ~ cauchy(0, scale);
  z ~ std_normal();  // implies theta ~ normal(mu, sigma)
  est ~ normal(theta, se_est);
}
"
model_noncentered <- cmdstan_model(write_stan_file(stan_code_noncentered))

# fit the model for one prior scale; return the draws of sigma and the divergences
fit_scale <- function(scale) {
  fit <- model_noncentered$sample(
    data = list(J = J, est = est, se_est = se_est, scale = scale),
    seed = 123,
    chains = 4,
    parallel_chains = 4,
    iter_warmup = 2000,
    iter_sampling = 2000,
    adapt_delta = 0.95
  )
  tibble(sigma_draws = list(spread_draws(fit, sigma)),
         divergent = sum(fit$diagnostic_summary()$num_divergent))
}

# one row per prior scale
scale_fits <- tibble(scale = c(5, 20, 100)) |>
  mutate(fit = map(scale, fit_scale)) |>
  unnest(fit)
# posterior of sigma for each prior scale
scale_fits |>
  unnest(sigma_draws) |>
  summarize(divergent = first(divergent),
            median = median(sigma),
            q05 = quantile(sigma, 0.05),
            q95 = quantile(sigma, 0.95),
            .by = scale)
# A tibble: 3 × 5
  scale divergent median   q05   q95
  <dbl>     <dbl>  <dbl> <dbl> <dbl>
1     5         0   2.74 0.236  9.92
2    20         0   4.65 0.480 14.7 
3   100         0   5.21 0.476 16.9 
# posterior densities of sigma
scale_fits |>
  unnest(sigma_draws) |>
  ggplot(aes(x = sigma, color = factor(scale))) +
  geom_density() +
  coord_cartesian(xlim = c(0, 30)) +
  labs(x = "sigma", y = "Posterior density", color = "Scale of the\nhalf-Cauchy prior")
  • Larger scale, larger sigma: the posterior median and 95th percentile both rise as the scale goes from 5 to 100.
  • Eight schools say little about sigma, so the prior matters.
  • Scale 5 pulls sigma toward zero and the school effects toward mu. Scale 100 lets them spread out.

Exercise 4 Red State, Blue State: Part 6

  • Part 4 fit a separate logit in each state.
  • Now fit one hierarchical model to all 50 states. Each state gets its own intercept, and the 50 intercepts come from a normal distribution.
  • This is the varying-intercept model behind Figure 3 of Gelman et al. (2007, p. 355) [pdf].
  • income varies across voters within a state. rs_state_median_income varies only across states: state median household income, rescaled to mean 0 and SD 0.5 across the 50 states.
  • Same CES data as Part 4. The code below adds rs_state_median_income.

Exercise 6 Ordered or Not? Gelpi and Paolino

  • March 2008 survey experiment on the war in Iraq (Gelpi; N = 1,000).
  • Each respondent read a short news story: successful military events in Iraq, unsuccessful events, or neither. Separately, a confident statement from President Bush (“no doubt … we will succeed”), a cautious statement, or neither.
  • Then: what do you think of a timetable for withdrawing all American troops from Iraq?
  • Paolino (2017): the answers are ordered. Ordered logit; the effects of the stories change linearly with approval of Bush.
  • Gelpi (2017): unordered. Multinomial logit, separately for each level of Bush approval.

Paolino, Philip. 2017. “Surprising Events and Surprising Opinions: The Importance of Attitude Strength and Source Credibility.” Journal of Conflict Resolution 61(8): 1795–1815.

Gelpi, Christopher. 2017. “The Surprising Robustness of Surprising Events.” Journal of Conflict Resolution 61(8): 1816–1834.

    • A treatment shifts \(\eta_i\) by the same amount for everyone at a level of Bush approval, so its effects on the two end categories have opposite signs (or are both zero).
