Exercise 1 Simulate and Recover; Ordered Logit

One important way to test and develop your understanding of statistical models and quantities of interest is to simulate a fake data set with known true quantity of interest (e.g., coefficients or first difference) and then recover that quantity of interest through your estimation procedure.

In Week 9, we did this for logit. See Simulate and Recover; Logit.

Do this for the ordered logit model in the notes. As your quantity of interest, use \(\Pr(y \geq 3)\) when income equals 1.5 and x2 equals "Label 1".

  1. First, simulate a fake data set with known cutpoints, coefficients, and quantity of interest. Write this code yourself; adapt your Week 9 code. Notice that the linear predictor eta has no intercept. The cutpoints alpha take its place. In the solution, I use the values below, but you can choose different values if you like (keep 1.5 among the values of income).
    • n = 10,000.
    • income: −2.5, −1.5, −0.5, 0.5, 1.5, or 2.5, equally likely.
    • x2: "Label 1" (about 75%) or "Label 2" (about 25%).
    • Cutpoints alpha: −1, 0.5, and 2 (so four categories).
    • Coefficients: 0.4 for income; 1 for x2 = "Label 2".
    • y an ordered factor, in a data frame named data.
    • Compute the true \(\Pr(y \geq 3)\) from the true values.
  2. Second, use MASS::polr() to fit an ordered logit model to the fake data. Are the true cutpoints and coefficients inside their 95% confidence intervals? (polr() calls the cutpoints “Intercepts” and labels them 1|2, 2|3, and 3|4.)
  3. Third, use predictions() to recover the true quantity of interest. Is the true value inside the 95% CI?
  4. Fourth, adapt the code to compute the true first difference in \(\Pr(y \geq 3)\) as income moves from −1.5 to 1.5 (with x2 equal to "Label 1"). Then recover it with comparisons().
  5. Fifth, refit the model with brm(family = cumulative("logit")). Recover the cutpoints, the coefficients, and the first difference. Compare with polr() and the truth.
Hint

\(\Pr(y \geq 3)\) is the sum of the probabilities of categories 3 and 4.

  • Week 6 added up category probabilities with hypothesis: Red State, Blue State: Part 2(a), part 3.
Complete solution

Part 1

Your code will differ. Here is one version.

# --- simulate a fake data set ---

# set seed for reproducibility
set.seed(1234)

# set sample size
n <- 10000  # needs to be large enough so that CI isn't super wide

# create explanatory variables
## numeric variable; six brackets, like income in the anes data
income <- sample(c(-2.5, -1.5, -0.5, 0.5, 1.5, 2.5), size = n, replace = TRUE)
## qualitative variable
x2 <- sample(c("Label 1", "Label 2"),
             size = n,
             replace = TRUE,
             prob = c(0.75, 0.25))  # about 75% will be "Label 1"

# create cutpoints and coefficients
alpha <- c(-1, 0.5, 2)  # J - 1 = 3 cutpoints, so J = 4 categories
b1 <- 0.4
b2 <- 1

# linear predictor; no intercept!
eta <- b1*income + b2*(x2 == "Label 2")

# cumulative probabilities Pr(y <= j), j = 1, 2, 3
cp1 <- plogis(alpha[1] - eta)
cp2 <- plogis(alpha[2] - eta)
cp3 <- plogis(alpha[3] - eta)

# category probabilities Pr(y = j), j = 1, 2, 3, 4; one row per observation
p <- cbind(cp1, cp2 - cp1, cp3 - cp2, 1 - cp3)

# simulate outcome for ordered logit model; one draw per observation
y <- numeric(n)
for (i in 1:n) {
  y[i] <- sample(1:4, size = 1, prob = p[i, ])
}

# combine into data frame; y must be an ordered factor for polr()
data <- data.frame(y = factor(y, ordered = TRUE), income, x2)

# truth: Pr(y >= 3) when income = 1.5 and x2 = "Label 1"
eta_c <- b1*1.5  # x2 = "Label 1", so the b2 term is zero
1 - plogis(alpha[2] - eta_c)
[1] 0.5249792

The true value of \(\Pr(y \geq 3)\) is about 0.525. Notice that \(\Pr(y \geq 3) = 1 - \Pr(y \leq 2) = 1 - \operatorname{logit}^{-1}(\alpha_2 - \eta)\), so we only need the second cutpoint.

Part 2

# fit ordered logit model
fit <- MASS::polr(y ~ income + x2, data = data, Hess = TRUE)

# estimates and 95% cis for the coefficients and the cutpoints
est <- c(coef(fit), fit$zeta)
se <- sqrt(diag(vcov(fit)))
cbind(truth = c(b1, b2, alpha),
      estimate = est,
      lower = est - 1.96*se,
      upper = est + 1.96*se) |>
  round(3)

Part 4

# truth: fd in Pr(y >= 3) as income moves from -1.5 to 1.5; x2 = "Label 1"
pr_hi <- 1 - plogis(alpha[2] - b1*1.5)
pr_lo <- 1 - plogis(alpha[2] - b1*(-1.5))
pr_hi - pr_lo
[1] 0.2752393

comparisons(fit,

Complete solution
f <- ft_donald_trump ~ (1 | social_group)
fit_trump <- brm(f, data = anes_ft, chains = 4, cores = 4, backend = "cmdstanr", seed = 1234)
# sample size and sample average for each group
group_summaries <- anes_ft |>
  summarize(n = n(), sample_average = mean(ft_donald_trump), .by = social_group)

# hierarchical estimate for each group, next to the sample average
p_trump <- predictions(fit_trump, newdata = datagrid(social_group = unique)) |>
  as_tibble() |>
  select(social_group, estimate, conf.low, conf.high) |>

Exercise 3 Red State, Blue State: Part 6

In Part 4, we fit a separate logit in each state using CES data. Now, we’ll fit one hierarchical model to all 50 states. Each state will have its own intercept, and we’ll model the 50 intercepts using a normal distribution.

This is the varying-intercept model behind Figure 3 of Gelman et al. (2007, p. 355) [pdf].

rs_state_median_income is a state-level measure of income that varies only across states. This is state median household income, rescaled to mean 0 and SD 0.5 across the 50 states.

# load data; 50 states
ces <- read_csv("https://pos5747.github.io/files/red-state-part4.csv")

# make a state-level data set
states <- ces |>
  distinct(state_name, state_abbr, state_median_income) |> 
  mutate(rs_state_median_income = arm::rescale(state_median_income)) |> 
  glimpse()

# add rescaled state income to the voters
ces <- ces |>
  left_join(select(states, state_name, rs_state_median_income), by = "state_name") |> 
  glimpse()
  1. Use brm() to fit the logit vote_rep ~ rs_state_median_income + (1 | state_name). Use family = bernoulli, backend = "cmdstanr", iter = 10000, and warmup = 2000. Check R-hat and the ESS.
  2. Use predictions() to compute Pr(Trump), with a 90% CI, for a voter in each state. Plot these 50 estimates and their CIs against state_median_income, labeled with the state abbreviations.
  3. Add a line for a typical state (i.e., a state whose intercept is exactly what state income predicts). Use predictions() with re_formula = NA over a range of state incomes.
  4. Interpret the coefficient for rs_state_median_income. What is the vertical distance between a state’s point and the line?
  5. Gelman et al. (2007) say that richer states lean Democratic. Does this model show this for 2024?

  • Distance from the line: the part of the state’s intercept that state income doesn’t explain (again, on the probability scale, however). These distances are the “varying” part of the varying intercept.
